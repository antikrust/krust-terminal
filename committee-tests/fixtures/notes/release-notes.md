# Release notes — v2.4

We are SUPER excited to announce the incredible new version 2.4 of the app!!! This release is packed full of amazing improvements that we think you're going to absolutely love.

## What's new

- We fixed the thing where it crashed. It doesn't crash any more now.
- Performance has been improved by making it faster in several places, so everything should feel snappier and more responsive than before, which is something a lot of you asked for.
- New dark mode!! (also light mode)
- Various bug fixes and improvements.
- The export button was moved. It's in a better place now.
- We also did some work under the hood which you won't see but which makes things better.

## Known issues

- Sometimes it might not work on some systems in certain situations. We are looking into this.
- The thing with the sync is still happening for a few people.

Thanks so much for being part of our journey!!! Please leave us a review, it really helps.
